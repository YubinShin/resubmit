# 제출용 공개본 구성 기록

이 공개본은 로컬 프로젝트의 소스 스냅샷을 별도 작업 폴더에서 정리한 것이다. 기준 스냅샷은 `75e284cd0940d00c28d929706614144a1769f543`이며, 기존 로컬 main과 개인 학습 자료는 보존했다. 기존 미게시 개발 커밋을 이 공개본의 부모 이력으로 포함하지 않는다. 과거에 공개된 원격 main의 기록을 지우거나 바꾼 작업도 아니다.

## 자료 구성

- 기존 번들 문제 CSV의 165개 행과 번들 로딩 경로를 제외했다. 외부 문제 원문이나 시험 복원 자료를 기본 배포 자료로 제공하지 않는다.
- 일반적인 알고리즘 유형은 유지하면서 내장 6개 fixture의 설명과 입력 예제를 공개본용으로 작성했다. 알고리즘 유형 자체의 독창성이나 독립적인 구현 숙련도를 주장하지 않는다. 이 정리와 검증에 Codex를 사용했다.
- 프로덕션의 Java 제출 규약, 실행 판정, 상태 머신, JSONL 이력, 리뷰 provider와 진단 흐름은 유지했다.
- RESUBMIT_CODE_RPG_HOME은 개인이 권한을 가진 로컬 카탈로그를 선택적으로 연결하는 기능이다. 해당 파일이나 외부 행의 채점 코드는 이 공개본에 포함하지 않으며, 가져온 행을 자동 실행 fixture로 승격하지 않는다.
- .env, 개인 .resubmit 기록, coding-test, bin과 원본 Git backup은 포함하지 않는다. Gradle Wrapper의 기존 라이선스 고지는 유지했다.

## 과거 LLM 평가와 공개 이력

평가 JSON의 commit 값은 각 실험을 수행한 로컬 이력의 ID다. 그 ID가 새 공개 Git 이력의 조상으로 존재한다고 주장하지 않는다. 기존 평가 기록의 SHA를 공개본의 새 commit으로 고쳐 적지 않았다.

배열 합계 골든셋과 기록된 실제 요청·응답·채점·usage, 평가 실행 도구는 기준 스냅샷과 바이트 단위로 동일하게 보존했다. 원본 manifest의 데이터·도구 해시와도 대조한다. 내장 CLI 연습 fixture 교체와 LLM 평가 사례 변경은 별개다.

이 공개본 정리에서는 실제 LLM을 추가 호출하지 않았다. 새 CLI 데모는 fixture 응답과 스크립트의 코드 교체를 사용한다. 과거에 실제 API 평가를 수행했다는 사실과, 현재 CLI 전체를 실제 API에 연결해 검증했다는 주장을 구분한다.

## 검증 범위

전체 빌드·테스트와 배포용 CLI 데모의 결과는 [검증 기록](validation/submission-check.md)과 [데모](demo.md)에 남긴다. 현재 문서의 정리는 데이터의 제외·작성·검증 과정을 설명하며, 모든 코드·아이디어의 독창성이나 법적 권리 검토 완료를 의미하지 않는다. 원격 게시와 CI 결과는 로컬 검증과 별도로 확인해야 한다.
