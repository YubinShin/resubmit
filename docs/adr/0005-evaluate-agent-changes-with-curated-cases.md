# ADR 0005: 선별된 사례로 agent 변경을 평가한다

- Status: Accepted
- Date: 2026-10-08

## Context

LLM 리뷰와 힌트는 같은 입력에서도 달라질 수 있다. 일반 단위 테스트는 응답 스키마와 workflow 동작을 검증할 수 있지만, 힌트가 정답을 너무 일찍 공개하는지 또는 실패 진단이 제출 근거와 맞는지는 별도 평가가 필요하다. 모든 CI 실행에서 실제 API를 부르면 비용과 외부 서비스 의존성이 생긴다.

## Decision

- 기본 CI는 빌드, 결정론적 테스트, 고정 fixture 평가를 사용하며 외부 LLM 호출을 요구하지 않는다.
- LLM 평가를 추가할 때는 버전 관리되는 선별 사례와 명시적인 평가 기준을 사용한다.
- 실제 API 기반 평가는 비용과 비밀정보를 고려해 기본 CI와 분리하고, 수동 또는 명시적으로 활성화한 workflow에서 실행한다.
- 평가는 판정·근거 일치, 단계별 힌트 적절성, 정답 조기 노출, 응답 실패율과 비용을 추적할 수 있게 설계한다.
- agent 평가 결과는 학습자의 제출 기록과 분리해 보관한다.

## Consequences

- 기본 PR 검증은 API 키 없이 재현 가능하다.
- 품질 평가는 평가 사례와 채점 기준의 품질에 의존하므로 변경 이력을 함께 관리해야 한다.
- 실제 LLM 평가를 CI에 연결할 때는 비용 한도와 회귀 차단 기준을 별도로 정해야 한다.
