# ADR 0004: 자기보고와 관찰된 숙련도를 분리한다

- Status: Accepted
- Date: 2026-10-08

## Context

초기 진단은 사용자의 자기평가와 실제 문제 풀이 결과를 함께 사용한다. 둘은 서로 다른 종류의 정보다. 자기보고를 테스트 결과로 덮어쓰거나 적은 수의 제출만으로 확정 점수를 만들면 진단 근거와 불확실성을 설명하기 어렵다.

## Decision

- 온보딩 답변은 사용자의 자기보고로 저장한다.
- 컴파일·테스트 결과, 풀이 시간, 힌트 사용과 수정 후 결과는 관찰 근거로 별도 저장한다.
- 초기 프로필은 자기보고와 관찰 결과를 구분해 보여주며, 관찰 근거가 부족한 항목은 미확인으로 표시한다.
- 다음 학습 제안은 관찰 근거와 선행 관계를 설명할 수 있어야 한다.
- MVP 진단은 여러 유형을 포함하는 4~6문제 workflow를 목표로 한다. 구체적인 문제와 시간 배분은 진단 세트에서 관리한다.

## Consequences

- 자기 인식과 실제 수행의 차이를 학습 계획에 반영할 수 있다.
- 프로필에는 근거와 표본 수가 필요하며, 단일 제출만으로 장기적인 실력 향상을 주장하지 않는다.
- 초기 진단 workflow는 현재 단일 문제 CLI 구현과 별도의 후속 범위다.
