# ADR 0006: 로컬 CLI 실행에 데이터베이스 서버를 요구하지 않는다

- Status: Proposed
- Date: 2026-10-08

## Context

프로젝트는 Kotlin CLI로 시작하며 사용자가 별도 서버를 설치·운영하지 않고 실행할 수 있어야 한다. 학습 기록과 문제·기술·선수 관계를 저장하는 방식은 목적에 따라 다르고, 그래프 탐색이 실제 추천에 필요한지 확인하기 전에 그래프DB를 필수 의존성으로 두면 첫 실행 장벽이 커진다.

## Decision

- 기본 CLI와 fixture 데모는 로컬 데이터 저장만으로 동작하게 한다.
- 그래프 기반 추천이 필요해지면 저장소 인터페이스 뒤에 Neo4j 구현을 추가하는 방안을 검증한다.
- Neo4j를 채택하더라도 로컬 설치를 필수화하지 않고 관리형 인스턴스 연결을 우선 검토한다.
- 사용자 학습 데이터와 CI 통합 평가 데이터는 분리하며, CI는 격리된 테스트 데이터 공간을 사용한다.

## Consequences

- 초기 실행에 로컬 DB 설치나 서버 프로세스가 필요하지 않다.
- 그래프DB 도입은 추천 요구사항과 탐색 질의로 효용을 확인한 뒤 결정한다.
- 관리형 DB를 실제로 연결할 때 연결 정보·비용·CI 격리 방식을 별도 결정해야 한다.
